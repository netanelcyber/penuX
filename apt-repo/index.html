⚡ kvmweb APT Repository

Lightweight KVM web management interface for Ubuntu and Debian.

Quick Install

# 1. Add the GPG key
curl -fsSL https://netanelcyber.github.io/penuX/apt-repo/kvmweb.gpg.key | sudo gpg --dearmor -o /usr/share/keyrings/kvmweb.gpg

# 2. Add the repository
echo "deb [signed-by=/usr/share/keyrings/kvmweb.gpg] https://netanelcyber.github.io/penuX/apt-repo stable main" \
  | sudo tee /etc/apt/sources.list.d/kvmweb.list

# 3. Install
sudo apt update && sudo apt install kvmweb

After Install

# Open in browser
https://<your-server-ip>:8080

# Service management
sudo systemctl status kvmweb
sudo journalctl -u kvmweb -f
