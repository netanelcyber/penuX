# 🚀 Deploy PenuX LDAP to Heroku

Complete guide to deploy PenuX LDAP directory on Heroku in minutes.

---

## ⚡ Quick Deploy (5 minutes)

### Option 1: Using Deploy Script (Recommended)

```bash
# 1. Make script executable
chmod +x heroku-deploy.sh

# 2. Run deployment
./heroku-deploy.sh

# 3. Follow prompts
# Enter app name prefix and passwords
# Script handles everything else
```

### Option 2: Manual CLI Setup

```bash
# 1. Install Heroku CLI
# From: https://devcenter.heroku.com/articles/heroku-cli

# 2. Login
heroku login

# 3. Create apps
heroku create penux-ldap-api
heroku create penux-ldap-web

# 4. Add database
heroku addons:create heroku-postgresql:hobby-dev --app penux-ldap-api

# 5. Set variables
heroku config:set \
  LDAP_HOST="ldaps://ldaps-server.penux.uk:636" \
  LDAP_BASE_DN="dc=penux,dc=uk" \
  LDAP_ADMIN_DN="cn=admin,dc=penux,dc=uk" \
  LDAP_ADMIN_PASSWORD="admin123" \
  --app penux-ldap-api

# 6. Deploy
cd services/openldap/api
git push heroku main

cd ../web
git push heroku main
```

### Option 3: Heroku Dashboard (No CLI)

1. Go to https://dashboard.heroku.com
2. Click **"New"** → **"Create new app"**
3. Name it: `penux-ldap-api`
4. Connect GitHub repository
5. Enable automatic deploys
6. Set environment variables
7. Deploy!

## 🔧 Configuration

### Environment Variables for API

```bash
LDAP_HOST=ldaps://ldaps-server.penux.uk:636
LDAP_BASE_DN=dc=penux,dc=uk
LDAP_ADMIN_DN=cn=admin,dc=penux,dc=uk
LDAP_ADMIN_PASSWORD=YourSecurePassword123!
CORS_ORIGIN=*
NODE_ENV=production
DATABASE_URL=(auto-generated by Heroku PostgreSQL)
```

### Environment Variables for Web

```bash
API_URL=https://penux-ldap-api.herokuapp.com
NODE_ENV=production
```

### Set Variables via CLI

```bash
# Set API variables
heroku config:set \
  LDAP_HOST="ldaps://ldaps-server.penux.uk:636" \
  LDAP_ADMIN_PASSWORD="YourPassword" \
  --app penux-ldap-api

# Set Web variables
heroku config:set \
  API_URL="https://penux-ldap-api.herokuapp.com" \
  --app penux-ldap-web

# View all variables
heroku config --app penux-ldap-api
```

### Set Variables via Dashboard

1. Go to https://dashboard.heroku.com
2. Click your app
3. Go to **"Settings"** tab
4. Click **"Reveal Config Vars"**
5. Add key-value pairs
6. Save

## ✅ After Deployment

### 1. Get Your URLs

```bash
# Via CLI
heroku apps:info --app penux-ldap-api
heroku apps:info --app penux-ldap-web

# Your URLs:
# https://penux-ldap-api.herokuapp.com
# https://penux-ldap-web.herokuapp.com
```

### 2. Test Services

```bash
# API Health Check
curl https://penux-ldap-api.herokuapp.com/api/health

# List users
curl -u "cn=admin,dc=penux,dc=uk:YourPassword" \
  https://penux-ldap-api.herokuapp.com/api/users

# View logs
heroku logs -f --app penux-ldap-api
```

### 3. Add Custom Domains (Optional)

To use your own domain (api.ldap.penux.uk):

**Step 1: Add domain to Heroku**

```bash
heroku domains:add api.ldap.penux.uk --app penux-ldap-api
heroku domains:add ldap.penux.uk --app penux-ldap-web
```

**Step 2: Get CNAME values**

```bash
heroku domains --app penux-ldap-api
# Shows: api.ldap.penux.uk → xxx-xxx-xxx.herokuapp.com

heroku domains --app penux-ldap-web
# Shows: ldap.penux.uk → yyy-yyy-yyy.herokuapp.com
```

**Step 3: Update DNS at your registrar**

```
Type: CNAME
Name: api.ldap
Value: xxx-xxx-xxx.herokuapp.com
TTL: 3600

---

Type: CNAME
Name: ldap
Value: yyy-yyy-yyy.herokuapp.com
TTL: 3600
```

**Step 4: Wait for DNS propagation (24-48 hours)**

**Step 5: Access via custom domain**

```
https://ldap.penux.uk
https://api.ldap.penux.uk
```

## 📈 Scaling & Monitoring

### View Metrics

```bash
# View app info
heroku apps:info --app penux-ldap-api

# View logs (live)
heroku logs -f --app penux-ldap-api

# View specific log lines
heroku logs --app penux-ldap-api | grep ERROR
```

### Increase Resources (Dyno Type)

```bash
# View current dyno
heroku ps --app penux-ldap-api

# Scale to Professional dyno
heroku ps:scale web=1:professional --app penux-ldap-api

# Dyno types:
# - Hobby (free, sleeps after 30 min inactivity)
# - Standard-1x ($7/month)
# - Standard-2x ($25/month)
# - Performance ($50+/month)
```

### Scale Database

```bash
# View database
heroku addons --app penux-ldap-api

# Upgrade PostgreSQL plan
heroku addons:upgrade heroku-postgresql:standard-0 --app penux-ldap-api

# Plans: hobby-dev (free), standard-0, standard-3, premium, etc.
```

### Scale Web Dynos

```bash
# Scale to 2 processes
heroku ps:scale web=2 --app penux-ldap-api

# Scale back to 1
heroku ps:scale web=1 --app penux-ldap-api
```

## 🐛 Troubleshooting

### App Won't Start

**Check logs:**

```bash
heroku logs -f --app penux-ldap-api
```

**Look for:**
- Missing environment variables
- Node.js version mismatch
- Buildpack issues

**Fix:**

```bash
# Set missing variables
heroku config:set VAR_NAME="value" --app penux-ldap-api

# Redeploy
git push heroku main
```

### LDAP Connection Failed

**Verify variables:**

```bash
heroku config --app penux-ldap-api | grep LDAP
```

**Test connection via API:**

```bash
curl -u "cn=admin,dc=penux,dc=uk:YourPassword" \
  https://penux-ldap-api.herokuapp.com/api/users
```

### High Costs

**Reduce spending:**

- Use Hobby dyno (free but sleeps)
- Use hobby-dev PostgreSQL (free)
- Reduce number of processes
- Monitor logs for inefficient queries

**View costs:**

```bash
heroku billing --app penux-ldap-api
```

### DNS Not Resolving

**Verify CNAME:**

```bash
nslookup api.ldap.penux.uk
# Should resolve to Heroku app
```

**Fix:**

1. Check CNAME record is correct
2. Wait for DNS TTL (usually 3600 seconds)
3. Clear browser cache
4. Try different DNS: `nslookup -server 8.8.8.8 api.ldap.penux.uk`

## 🔐 Security Tips

After deployment:

1. **Change default passwords:**

```bash
heroku config:set \
  LDAP_ADMIN_PASSWORD="NewPassword123!" \
  --app penux-ldap-api
```

2. **Enable forced HTTPS:**

```bash
heroku config:set \
  FORCE_HTTPS="true" \
  --app penux-ldap-web
```

3. **Monitor logs for errors:**

```bash
heroku logs -f --app penux-ldap-api | grep -i error
```

4. **Set up backups:**

```bash
# Enable automatic backups
heroku pg:backups:schedules --app penux-ldap-api
```
