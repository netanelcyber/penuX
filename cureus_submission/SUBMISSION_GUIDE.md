## Step 2 — Start Submission
1. Go to: https://www.cureus.com/submit
2. Click "Submit New Article"
3. Select article type: **Original Article**
4. Select channel: **Internal Medicine** or **Gastroenterology** or **Health Technology**

Cureus has an online editor. Paste sections in order:
1. Introduction
2. Methods
3. Results (tables can be pasted as plain text or built in editor)
4. Discussion
5. Conclusions
6. Additional Information (conflicts, funding, data availability)
