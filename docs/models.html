SAP Severity Heuristic BISAP / Ranson

מודל לוגיסטי לניבוי לבלב חריף חמור. מיישם את Revised Atlanta Classification 2012 עם משקלים מ-BISAP וקריטריוני Ranson.

logit = −1.8 + 0.015 × max(0, age − 55) + 0.15 × [זכר] + 0.08 × max(0, WBC − 12) + 0.004 × max(0, CRP − 150) + 0.30 × max(0, Creatinine − 1.5) + 0.015 × max(0, BUN − 25) + 0.002 × max(0, Glucose − 200) + 0.001 × max(0, LDH − 250) + 0.03 × max(0, Hematocrit − 44) + 0.002 × max(0, AST − 250) − 0.30 × max(0, 3.5 − Albumin) − 0.40 × max(0, 8.0 − Calcium) + 0.05 × max(0, Bilirubin − 3.0) p = 1 / (1 + e^−logit)

General Sepsis Risk SIRS + Sepsis-3

מודל לוגיסטי לאיתור סיכון ספסיס מבדיקות שגרה. משלב SIRS (White et al. 1992) ו-Sepsis-3 (Singer et al. 2016) עם מרקרי תפקוד איברים.

SIRS_score = +1 if WBC > 12 or WBC < 4 [לויקוציטוזיס/פניה] +1 if HR > 90 [טכיקרדיה] +1 if RR > 20 [טכיפניאה] +1 if Temp > 38.3 or < 36 [חום/היפותרמיה] qSOFA_score = +1 if RR ≥ 22 +1 if SBP ≤ 100 organ_score (Sepsis-3): +0.18 if Creatinine > 2.0 mg/dL [אי-ספיקת כליות] +0.10 if Bilirubin > 2.0 mg/dL [אי-ספיקת כבד] +0.15 if Platelets < 100×10³ [תרומבוציטופניה] +0.20 if Lactate > 2.0 mmol/L [חמצת לקטית] +0.30 if Lactate > 4.0 mmol/L [הלם ספטי] +0.08 if SpO2 < 94% [היפוקסיה] +0.20 if MAP < 65 mmHg [היפוטנסיה] logit = −2.9 + 0.55 × SIRS_score + 0.65 × qSOFA_score + 3.5 × organ_score + 0.05 × [גיל > 65] p = 1 / (1 + e^−logit)

Pancreatic Sepsis Risk נמק + DIC

מודל לאיתור ספסיס שמקורו ספציפית בלבלב: נמק לבלבי מוגלתי (infected pancreatic necrosis). מבוסס על IAP/APA Guidelines 2013 ו-Blamey 1984.

score (פיצ'רים ספציפיים ללבלב): +0.18 if Lipase > 3000 U/L [דליפת אנזים מנמק] +0.10 if Lipase > 600 U/L +0.12 if Amylase > 1000 U/L [נמק מתמשך] +0.05 if Amylase > 300 U/L +0.18 if CRP > 150 mg/L [מרקר נמק — Blamey] +0.06 if CRP > 50 mg/L +0.14 if Ca²⁺ < 1.9 mmol/L [ספוניפיקציית שומן] +0.07 if Ca²⁺ < 2.0 mmol/L +0.14 if NLR > 15 [תשישות חיסונית] +0.08 if NLR > 10 [NLR = Neutrophils / Lymphocytes] +0.12 if Albumin < 30 g/L [third-spacing מנמק] +0.05 if Albumin < 35 g/L +0.12 if Fibrinogen < 2 g/L [DIC ממקור לבלבי] +0.04 if Fibrinogen > 5 g/L [phase חריפה] +0.08 if D-dimer > 5 [DIC] +0.04 if D-dimer > 2 organ_score (משקל נמוך יותר): +0.08 if Creatinine > 2.0 mg/dL +0.10 if Lactate > 2.0 mmol/L +0.08 if pH < 7.35 logit = −3.2 + 4.0 × score + 0.06 × [גיל > 65] p = 1 / (1 + e^−logit)

פרשנות קלינית

ספסיס לבלבי vs. SAP: ההבדל

SAP (Severe Acute Pancreatitis) מוגדר לפי Atlanta 2012 על ידי כשל איברים מתמשך (>48 שעות). ספסיס לבלבי הוא זיהום ספציפי של הנמק — Infected Pancreatic Necrosis (IPN) — המופיע ב-20–40% מחולי SAP, בדרך כלל שבועיים מהאשפוז.

מרקרי IPN: CRP>150, Ca²⁺<1.9, NLR>10, ליפאז>3000 — אלה המרקרים שהמודל שלנו משתמש בהם.

ממצא: mild AP עם סיכון ספסיס גבוה

13 מתוך 14 המקרים עם high pancreatic sepsis risk מסווגים כ-mild לפי ICD. פרופיל מעבדתי: ליפאז>1000 + CRP>150 + Ca<1.5 + NLR>15 + אלבומין<30 + D-dimer>5.

פרשנות: ייתכן שאלה חולים עם infected necrosis שלא זוהה בסיווג ה-ICD המקורי — מחייב validation עם תרביות.
