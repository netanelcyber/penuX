Algorithm Descriptions

Logistic Regression

Linear model with L2 regularisation (C=0.5). Features scaled with StandardScaler. Optimal threshold: 0.575 by maximum F1.

Key features: Lymphocytes, Calcium, Creatinine, Lactate, LDH. Interprets all features simultaneously — fully interpretable.

sklearn LogisticRegression · max_iter=1000 · random_state=42

Random Forest ★

200 decision trees, max_depth=6, min_samples_leaf=5. Averages predicted probabilities across trees. Highest AUC (0.877).

Robust to missing values (fillna=0), no normalisation required. Key features: Calcium, D-dimer, LDH, Lactate, Hematocrit.

sklearn RandomForestClassifier · n_estimators=200 · max_depth=6

Gradient Boosting

150 shallow trees (max_depth=3), learning_rate=0.05. Highest F1 (0.918). Relatively low threshold (0.35) — achieves high sensitivity early.

Key features: D-dimer, Calcium, LDH, Lactate, Hematocrit — similar to RF, confirming stability.

sklearn GradientBoostingClassifier · n_estimators=150 · lr=0.05

Limitations: No external test set — all figures from cross-validation on the same Chinese cohort (n=722). Class imbalance: 585 severe vs 137 mild. Not validated on Western cohorts.
