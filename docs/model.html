Pathogen Class Prediction (MIMIC)

Hybrid deep-learning pipeline for ICU microbiology culture classification using MIMIC-III/IV critical-care data

Pipeline Overview

The penuX pathogen prediction pipeline is trained on MIMIC-III and MIMIC-IV, two of the largest publicly available critical-care databases. Records are linked across admissions, microbiology events, medication orders, and nursing charted vital signs to construct a multimodal feature set for each culture event.

Positive culture results are mapped to one of 12 clinically meaningful pathogen classes, enabling the model to predict the likely organism class from admission-time features before culture results are available. The target application is hypothesis generation and triage support in research settings.

Data sources: MIMIC-III v1.4 and MIMIC-IV v2.x (PhysioNet). Access requires credentialed training and data use agreement.

Model Architecture

The model is implemented in PyTorch and uses a hybrid fusion strategy that combines three independent feature streams before a joint classification head.

Text Features

Clinical note embeddings and discharge summary snippets encoded via a lightweight transformer encoder. Captures physician-recorded infection indicators.

Vital Signs

Time-series of charted vitals (temperature, HR, BP, SpO₂, RR, GCS) aggregated over the first 24–48 hours of ICU admission.

Medication Features

Antibiotic and antimicrobial orders encoded as a binary feature vector, reflecting empiric therapy choices made prior to culture reporting.

Fusion & Head

Feature streams are concatenated and passed through a fully-connected classification head with dropout regularization and softmax output over 12 classes.

Evaluation Metrics

The model is evaluated on a held-out test split stratified by admission. The following metrics are reported across all 12 pathogen classes:

Metric Description Scope
Accuracy Overall correct classification rate across all 12 classes Macro / weighted
F1 Score Harmonic mean of precision and recall; weighted for class imbalance Per-class & macro
ROC-AUC Area under receiver operating characteristic curve (one-vs-rest) Per-class & macro
ECE Expected Calibration Error — reliability of predicted probabilities Global
Brier Score Mean squared error of probabilistic predictions; lower is better Per-class & macro
