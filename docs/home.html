penuX — Clinical AI Research Platform

Open-source ML pipelines for ICU pathogen prediction and pancreatitis severity scoring

penuX provides reproducible machine learning pipelines trained on critical-care datasets. The platform targets two high-impact clinical domains: ICU pathogen class prediction using MIMIC-III/IV data, and early severity stratification for severe acute pancreatitis. All models are intended for academic research and benchmarking only.

SAP Severity Prediction

Early severity scoring for severe acute pancreatitis from 24-hour admission data. Benchmarked against established clinical scores: BISAP, APACHE II, Ranson, and Modified CTSI.

Pathogen Class Prediction

A hybrid deep-learning pipeline that classifies ICU culture results into 12 pathogen categories using combined text, vital-sign, and medication features extracted from MIMIC-III and MIMIC-IV.
