Severe Acute Pancreatitis
Severity Prediction

Early severity stratification from 24-hour admission data using the 2012 Revised Atlanta Classification

Overview

PenuX-AP-Severity provides research-grade machine learning models for predicting progression to Severe Acute Pancreatitis (SAP) using only data available within the first 24 hours of hospital admission — before imaging and specialist review are typically available.

Three complementary prediction scenarios are evaluated, covering general sepsis risk, pancreatic-specific sepsis risk, and a composite SAP severity heuristic.

2012 Revised Atlanta Classification

GradeDefinitionOrgan Failure
MILD No organ failure, no local or systemic complications None
MODERATELY SEVERE Transient organ failure and/or local/systemic complications < 48 hours
SEVERE Persistent organ failure — primary outcome > 48 hours

Clinical Score Benchmarks

All models are evaluated against established validated scoring systems when the required fields are present:

BISAP
Bedside Index for Severity in Acute Pancreatitis — 5-item admission score
APACHE II
Acute Physiology and Chronic Health Evaluation — 12 physiologic variables
Ranson Criteria
11-point scoring at admission and 48 h for severity prediction
Modified CTSI
CT-based morphologic severity index for local complications
