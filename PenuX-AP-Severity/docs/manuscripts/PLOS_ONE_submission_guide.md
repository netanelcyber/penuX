# PLOS ONE submission guide — field by field

This is the practical, "what do I actually click and paste" companion to the
manuscript draft and cover letter. Actual submission has to be done by you —
here is exactly what each step involves.

## 0. Before you start
- Read the current author guidelines once, since portal fields change over
  time: https://journals.plos.org/plosone/s/submission-guidelines
- Have ready: an ORCID iD (create free at https://orcid.org if you don't
  have one — PLOS ONE asks for it), and a final decision on affiliation
  wording (the draft uses "PenuX Research Group (independent research
  project)" — keep or change as you prefer).
- PLOS ONE accepts **format-free initial submission** — you do not need to
  re-format the .docx to their house style before first submission; that
  only matters if/after the paper is accepted.

## 1. Create an account / log in
Go to https://www.editorialmanager.com/pone/ and register (or log in). This
is the actual submission portal (Editorial Manager).

## 2. Start a new submission → choose "Research Article"

## 4. Manuscript checklist PLOS ONE will run automatically
- Their system (PACE / auto-checks) flags missing sections — the draft
  already includes Ethics Statement, Data Availability, Funding, Competing
  Interests, Author Contributions, so these checks should pass.
- No supplementary figures are included in this draft (the manuscript is
  text/tables-only, consistent with the analysis). If you want figures
  (e.g. an AUROC comparison plot), that's a separate step — let me know and
  I can generate publication-quality figures to attach.

## 5. After you click submit
- You'll get a manuscript tracking number by email immediately.
- Typical PLOS ONE timeline: editorial screening (1–2 weeks) → peer review
  (usually 2–4 months) → decision.
- **Do not submit to Scientific Reports or BMC MIDM while this is under
  review anywhere** — simultaneous submission of the same manuscript is a
  publishing-ethics violation. Only move to the next journal if this one
  is rejected.
